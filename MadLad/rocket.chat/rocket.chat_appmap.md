# rocket.chat: application map (stage 02, deep mode)

Structure and purpose only: which area of Rocket.Chat 9.1.0-develop (commit `9f3d6c8c48911e32ed6c2ce36befd431faa71190`) lives where, what it does, and which catalogue class (`deploy/knowledge/catalog/web_app_features.md`) it belongs to. Vulnerability detail is in `02_features.md`; per-feature detail in `features/<class>.md`. Paths are relative to `targets/rocket.chat/`.

## Request path

1. A request reaches the in-house Hono HTTP server (`apps/meteor/server/lib/http/`, `packages/http-router/src/`), which runs the base middlewares (`apps/meteor/server/lib/http/baseMiddlewares.ts`: Force SSL, instance id header, security headers and CSP from `apps/meteor/server/lib/cors/cors.ts`).
2. REST under `/api/v1/*` and `/api/*` goes to the `APIClass` router (`apps/meteor/server/api/ApiClass.ts`, `apps/meteor/server/api/router.ts`): client address, CORS, authentication by `X-User-Id`/`X-Auth-Token` or OAuth bearer, permission and license middlewares, rate limiter, body and query validation, then the route handler in `apps/meteor/server/api/v1/*.ts`.
3. WebSocket upgrades on `/websocket` and `/sockjs/...` go to the in-house DDP server (`apps/meteor/server/lib/realtime/`, `packages/ddp-server/src/`), which runs the remaining Meteor methods and the streams (`packages/streamer/src/`).
4. Everything else falls through to Meteor's `WebApp.connectHandlers`: file serving, avatars, OAuth, webhooks under `/hooks`, the Livechat page, the web client bundle.
5. Handlers call services and models (`apps/meteor/server/services/`, `packages/models/src/models/`) over MongoDB, with NATS as the service-broker transport.

## Shared stores

| Store | Written by | Read by |
|---|---|---|
| `users` | registration, login, OAuth linking, profile, admin, importers, 2FA | every authenticated request, directory, notifications, OAuth `userinfo` |
| `rocketchat_room`, `rocketchat_subscription` | room and team management, joins, invites, bans, DMs | room access validators, streams, notifications, file download |
| `rocketchat_message` (and its trash) | messages, integrations, apps, importers, direct reply, Livechat | history, search, threads, streams, notifications, AI search |
| `rocketchat_uploads` and GridFS | uploads, Livechat uploads, UIKit files, apps, importers | file serving, message attachments, thumbnails |
| `rocketchat_settings` | admin, setup wizard, environment overrides | every feature, public settings for anonymous clients |
| `rocketchat_integrations` | admin integration UI, `/hooks/add` | `/hooks/*`, outgoing triggers |
| `rocketchat_livechat_visitor` and contacts | Livechat widget, SMS, apps | agents, contacts, Livechat APIs |
| `rocketchat_oauth_*` | OAuth app admin, consent, token grants, dynamic registration | OAuth endpoints, REST bearer authentication, MCP |
